# ADR-0009 域路由与排序治理键族

- **状态**：已采纳（逐键拨启制——键族默认关交付、逐键过判据后随部署窗拨启；2026-10-03 回填建档）
- **日期**：决策日 2026-09-29/30（主体）+后续逐键；建档日 2026-10-03（回填建档）
- **决策记录**：内部过程档（决策登记在案）
- **关联**：route_domain.py+词表 v2；rag.py（decrowd/famsel/scope 面）；设计稿见内部过程档

## 背景

检索排序病灶集中四型挤占（表格洪流/同族霸屏/换域块上位/深射程外）；治理面走"键族制"而非一次性重写：每键独立、默认关、判据先定后测、可单键回退。

## 决策

①**域路由**：route_domain.py+词表制（D5 多域冲突默认 fallback；D9 词表扩改逐次决策、禁自动生效）；route_enabled 经作者明示解除 D6 逐期放行、随轻部署窗拨 true。
②**P0 三键**：table_downweight 0.85+spec_suppress 0.85+decrowd_candidates 200（**不上 doc 配额**；干净档依据=验证矩阵四卷零代价+top5 占席 12→0）。
③**乙案 famsel 族选席**：family_select_enabled（scope=miit+clone/words=full/margin=1，池深联动 decrowd 200）。
④**装载面扩三字段**：corpus_type/chunk_type/source_domain 入 META_FIELDS（带内存评估闸——小内存硬约束）。
⑤**scope=tables 变体**：table 降权作用域收窄表格块（s300_85 臂全维度净胜：G18 正文 19→in5、对抗卷 145→149 零退化；2026-10-02 随收尾窗上产=scope "all"→"tables"）。

## 理由与判据

键族制=归因干净（单变量消融）、回退廉价（单键）、与评测门禁（ADR-0008）天然衔接；每次拨键都有预冻结判据矩阵。

## 替代方案（含被否原因）

- 一次性排序器重写（弃——归因混乱、回退面大）
- doc 配额制（弃——P0 决策明确不上）
- 全局 table 降权维持 all 作用域（被 scope=tables 变体取代——all 档对非表格域有盲区）

## 后果

- **正向**：famsel 触发率 9.3% 健康、route 首例正确回退在档；键面漂移有整树等价断言护栏。
- **负向/风险**：键面跨窗漂移风险（曾遇并行会话预拨与窗目标态恰合——拨键断言须含"既有键零触碰"成操作纪律）；词表 v2 后续扩改仍须逐次决策。
- **回滚**：每键单键回 false；scoped 两键回 "all"。
