# ADR-0004 BM25混合检索上产与现库态净负复核

- **状态**：已采纳→**决策关停全量形态（限域门控形态接续，另立 ADR）**；2026-10-03 回填建档
- **日期**：决策日 2026-09-19（上产）；复核 2026-10-02；建档日 2026-10-03（回填建档）
- **决策记录**：内部过程档（决策登记在案）
- **关联**：rag.py（hybrid 检索段）；判定/复核材料见内部过程档

## 背景

纯余弦检索对词法精确匹配（表号/术语缩写）覆盖不足，优化路线图纳入 BM25 混合检索（hybrid 分层），先默认关后随部署窗拨键入产。

## 决策

①BM25 混合检索上产（默认关起步，随部署窗拨开）——上产时点依据=Y 卷 +12.5pp。
②2026-10-02 排序优化阶段1 复核：**产线 BM25 混合段在现库态净负**（无 hybrid 分层臂读数 C 卷 −5、S1V-03、ADV −3、H −1；与 09-19 上产依据已时过境迁——Y 现 8/8 与池无关）。
③复核件处置=**批转评测线**：门禁 channel=cosine 口径偏差复核+两档动作案裁夺归评测线，动键随部署窗。

## 理由与判据

上产与复核都以"判据先定后测"的四卷/S1/ADV 读数为尺；净负结论来自真基线臂（生产十键管线离线复刻，服务对拍 192/192 逐位一致）。

## 替代方案（含被否原因）

- 维持纯余弦单路（当时比测弱势，词法面缺口）
- hybrid 池配软融合序（阶段1 消融发现"hybrid 池必须配软融合序"——观察登记，未见独立决策）

## 后果

- **正向**：词法精确匹配能力曾入产；复核机制证明键面可被后续证据推翻重议。
- **负向/风险**：门禁本地跑读本地 config（十键仅生产拨过）→门禁读数证的是纯余弦视图、产线实际读数有偏差（归评测线核对）；键面动作悬置期间生产维持现态。
- **回滚**：hybrid 键回 false（单键回退，键位=BM25/hybrid 分层开关族）。
