# ADR-0011 rerank路线决策树

- **状态**：已采纳→**终判关闭（二次，2026-10-03 rerank 1b 判据①挂，预登记条款生效）**；2026-10-12 判死实验后重开资格成立（拒答信号姿态）
- **日期**：决策日 2026-10-02（二期立案+三项决策）；建档日 2026-10-03（回填建档）
- **决策记录**：内部过程档（决策登记在案）
- **关联**：训练包/实验档见内部过程档；生产 rerank 键维持留档关

## 背景

rerank 是检索最后一块杠杆但三度受挫：批次B 离线试点三判据不过、阶段1 五组消融+组合终验三席全负（根因=零样本 reranker"拉深位块上位"与 S1 负控结构性互斥）；托管精调不支持 reranker、商用 rerank API 存在、消费级 GPU 短租可得三事实核实后立决策树。

## 决策

①**批次0 探底**（费帽=个位数元级）：商用 rerank API 探底——default 臂 ADV 54/60✓/四卷 C24✓/H35✓/**唯 S1 负控 8/15<9 差 1 题**=零样本结构性失败面加冕，走负结果分支；蒸馏教师=default 臂分数（四档全量留档）。
②**批次1 LoRA 微调**（费帽=十元级）：订阅通道合成 1.5-2.5 万对（偏重陷阱模式域）+难负例挖掘（S1 36 题种子混入）→消费级 GPU 短训→ONNX int8 回本机→缓存管线重打分复测→过线上对抗卷-1.0 终验；**数据不出境、评测题零污染闸为硬纪律**。
③**止损=三连负终判关闭**：判据①（S1 负控 ≥9）再挂即 rerank 线终判关闭。
④生产化过线才谈（API 路直接接入；微调路单题 87s/50 候选 CPU int8=线上同步检索不可用，须先解运行时：GPU/异步/缩池）。

## 理由与判据

判据纪律全沿用（先定后测/合成题禁入评测/S1 与对抗卷 210 冻结到终验/0 生产改动/登记不自动生效）；探底实耗在个位数元级费帽内。

## 替代方案（含被否原因）

- 托管精调（弃——不支持 reranker 且无权重导出）
- 零样本 reranker 直接上产（弃——两引擎同挂判据①=结构性失败面）
- 海外免费 GPU（备选——数据出境分级审查未过前不用，境内短租数据不出境优先）

## 后果

- **正向**：API 分数四档留档=蒸馏教师就位；训练包一键化（开卡即训）；负结果全归档可复核。
- **负向/风险**：微调若不过=rerank 线终判关闭（三连负止损已预登记）；运行时约束悬置。
- **回滚**：全程 0 生产改动；生产 rerank 键维持留档关（ADR-0010③）。
