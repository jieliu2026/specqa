# ADR-0013 会话重新生成替换语义

- **状态**：已采纳（2026-10-03）
- **日期**：决策日 2026-10-03（当日两轮决策：内容决策+ADR 立项）；建档日 2026-10-03
- **决策记录**：内部过程档（决策登记在案）
- **关联**：server.py 头注"二期批A 重新生成改替换"段（X-QA-Regen 契约权威表述）；tests/test_conversations_regen.py（后端 9 例）；tests/test_frontend_phase2.py（前端面 3 例，例③=A2 regen 全链路）；tests/test_frontend_actions.py（onRegen 本地替换语义断言）；config 键名 conversations_enabled（只写键名不写值）

## 背景

前端"重新生成"（onRegen）本地语义已是替换——App.vue splice 删末轮后重发（test_frontend_actions 有断言）；而服务端会话库（批次D 双写）沿用追加，两套历史裂开：切回该会话恢复时旧答案重现。二期批次A A2 决策门（服务端替换 vs 前端折叠）由此开。

## 决策

①/api/chat 新增**可选请求头 X-QA-Regen: 1**（仅该值严格生效）。
②与**显式合法 conv id** 续写组合时：双写 user 侧落库前先删该会话末轮——_Store.delete_last_round=**最后一条 user 消息及其后全部消息**（孤 user 断流形态一并覆盖），再写本轮 user；重新生成后服务端历史与前端一致（旧轮不残留，恢复会话旧答不重现）。
③防御边界：头缺省/值非 1/conv id 缺省或非法或非本设备 → 行为与既往**逐字节一致**（regen 静默忽略+自动建新会话）。
④conversations_enabled=false → 双写整体跳过，regen 头自然无效；既有端点/事件面/SSE data 断言面零改动（additive）。

## 理由与判据

决策评审附关键新证：前端 onRegen 本地已是替换语义、痛点在服务端库追加——切回会话旧答案重现；案① 使服务端向前端语义对齐（恢复面单一事实源）。判据先定后测：判据预登记先落盘、后施工测判（材料见内部过程档）。

## 替代方案（含被否原因）

- 案② 前端折叠（旧答折叠标记、服务端库不动）：弃——无服务端落点，跨设备恢复失效
- 维持现状（服务端追加）：弃——切回会话旧答案重现（本案痛点本体）

## 后果

- **正向**：服务端历史与前端一致（恢复面旧答不重现）；验证在案=后端新 9/9（test_conversations_regen）+前端 phase2 3/3（例③全链路：请求带 X-QA-Conv-Id+X-QA-Regen:1，reload 后服务端恢复序列=替换后）+conversations 20 例零破坏；错误轮（assistant content=错误 SSE 事件 JSON 原文）同样可替换，旧错答不残留。
- **负向/风险**：regen 落库前删末轮不可逆——误触发即丢旧轮；防御面=三重门（头值严格"1"+显式合法 conv id+本设备归属），跨设备冒用→静默换新会话、A 侧零污染。
- **回滚**：软回退=conversations_enabled 键置 false（双写整体跳过、regen 头自然无效，秒级）；代码面=git revert（批次A 提交边界内）。
