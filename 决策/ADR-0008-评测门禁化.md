# ADR-0008 评测门禁化

- **状态**：已采纳（2026-10-03 回填建档）
- **日期**：决策日 2026-09-28→10-01（多轮决策成型）；建档日 2026-10-03（回填建档）
- **决策记录**：内部过程档（决策登记在案）
- **关联**：建库/scripts/门禁线-生产.json；eval_gate.py（在本仓）；题卷制度材料见内部过程档

## 背景

评测从"跑卷看数"升级为"变更触发阻断"的守护位；判卷面经命题口径轮1/2 实战暴露 judge-判官一致率、服务端非确定性等问题，制度随之收敛。

## 决策

①**eval_gate.py 单一入口**+多卷硬线阻断+S1 负控两级分层（A 级 7 题硬线随换库必跑、B 级 8 题观察级移出硬线+回收条件三档）。
②**faithfulness 门禁** 0.70→**0.75**（依据=生成评审分离重构了结+T3 实测 0.95）。
③**两判官制**：甲乙一致即定、1:1 分歧入作者裁决队列（2026-10-01 作者裁定"不必复位，甲乙就够了"——取代四判官 ≥3 表决与扩员）。
④**对抗卷 1.0 定线**：有答案 doc 命中 ≥135/180+拒答 abstain ≥20/30（首测实值 153/26 在档；pass_lines 已落卷面）。
⑤判据纪律：**先定后测**（失败的尺子不悄悄换）、合成题禁入评测、S1 与对抗卷 210 冻结到终验。

## 理由与判据

门禁线全部锚定既有基线读数（多卷/S1 三线/faithfulness）；判官制度演化以轮1/2 一致率数据为据（68.8%→85.5% 收敛实证）。

## 替代方案（含被否原因）

- 四判官表决 ≥3 多数定（弃——2026-10-01 作者决策两判官制取代）
- judge 初判分流（弃——轮1 一致率 68.8%<90% 线，judge 转观察位）
- 门禁线一次定死不容收紧（弃——faithfulness 0.70→0.75 为数据驱动收紧先例）

## 后果

- **正向**：回归守护达"变更触发阻断"水位；换库/拨键均有硬线护栏；两池毕业制衔接挑战池健康带。
- **负向/风险**：门禁口径偏差疑似（本地 config 键面 vs 生产拨键，ADR-0004 联动）归评测线核对；时间敏感测试脆弱性（换月打穿 token_budget 四测）在案。
- **回滚**：门禁线调整=门禁线配置键面（收紧/放宽均登记）；两判官制为决策位制度、回改须作者。
