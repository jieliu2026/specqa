# ADR-0003 成本红线双线分账机制

- **状态**：已采纳（现行线位=月度预算预警线+熔断线双闸，量级百元级/月；2026-10-03 回填建档）
- **日期**：决策日 2026-09-18（其后多轮调线）；建档日 2026-10-03（回填建档）
- **决策记录**：内部过程档（决策登记在案）
- **关联**：生成侧用量台账 jsonl（内部维护）；成本闸代码在嵌入/生成管线内

## 背景

模型 API 按量调用（embedding/LLM 生成）为真金成本，须防两线互相掩盖与无感超支；兼容口默认开思考模式曾致输入侧实测为预览估 2.3 倍（附带教训）。

## 决策

①**embedding 按量累计红线制**：超限停手报备，累计口径含已发生用量；配预警线（触预警线打 warn 照常、触红线停手）。
②**LLM 生成侧单列授权与台账**（生成用量.jsonl），与 embedding 红线**分账不混记**。
③生成管线一律 `enable_thinking=false`（热修，三管线已修）。

## 理由与判据

累计制+分账=两线余量各自可见；台账行制=防累计行重复计数（naive 求和陷阱，曾发生 22 行改判案）；调线一律作者批、一批一次。

## 替代方案（含被否原因）

- 月度预算重置制（弃——累计制更能反映真实消耗池；后续演进为月度预算+双闸时保留累计台账口径）
- 单线总账（弃——两线性质不同：embed 有明确重建性、生成有订阅/现金双通道）

## 后果

- **正向**：历次调线全部在案可审计；双线余量日常可见（各线金额量级=十元级到百元级，定性口径）。
- **负向/风险**：余量趋紧时高频触发评审；订阅等价/现金双口径易误记（改判案在册）。
- **回滚**：调线=登记位追加，不回抹历史。
