# 决策/（ADR·架构决策记录）——索引与规程

本目录是 specqa 的**架构决策登记面**（ADR，Architecture Decision Record）：承载架构/技术选型级决策的长效档案（背景/决策/理由/替代方案/后果），append-only——正文不改写，变更只追加"调线记录"。

> **公开精选集说明**：本目录为生产系统 ADR 库的公开精选集（12 篇，覆盖检索、成本、鉴权、评测、前端、CI 等主线主题），经脱敏整理导入；完整 ADR 库与配套决策材料由项目方在内部维护（下文统称"内部过程档"）。

## 一、状态生命周期

```
草案（登记待采纳）
  → 已采纳（决策记录在案）
    → 已被取代（新 ADR 承接；旧 ADR 只改头部状态行+尾部追加调线记录，正文不动）
    → 已废弃（决策撤销且无承接 ADR）
```

制度要点：**登记待采纳、采纳归作者、禁自动生效**——ADR 草案不构成生效依据，生效以决策登记为准；证据材料与决策记录分档，ADR 属详情层、不承载证据原件；防自证——ADR 只重组既有登记/材料内容，不新增证据、不自立台账数字。

## 二、触发标准（什么决策写 ADR）

- **写**：凡涉及①改变系统边界或技术选型②引入或关闭一条技术路线③影响回滚能力④影响其他线（评测线/部署）依赖口径的决策。
- **不写**：单题处置、日常运营流水（留过程日志即可）。

## 三、写作规程

1. 编号四位顺序分配（ADR-0001 起），**编号永不复用、文件永不改名**；标题禁全角冒号/问号。
2. 新建 ADR=复制 `模板.md`，按模板填写。
3. 正文 append-only：决策变更/调线一律在尾部"调线记录"追加，不改正文。
4. 日期只进正文不进文件名（ADR 是活档，状态会变）。
5. **安全纪律**：ADR 内禁口令/key/公网 IP/域名实值；引配置只写键名不写值；内部成本金额一律定性表述。
