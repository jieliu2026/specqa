# ADR-0012 前端Vue港口与scp部署形态

- **状态**：已采纳（2026-10-03 回填建档）
- **日期**：决策日 2026-10-03（批次0/B/D 当日完工上产）；建档日 2026-10-03（回填建档）
- **决策记录**：内部过程档（决策登记在案）
- **关联**：frontend/（Vue3 工程在本仓）；部署 runbook 见内部过程档

## 背景

vanilla 单文件前端（927 行）行为稳定但维护性到顶；作者四问均授权"更彻底、专家一般用哪个"→框架迁移与部署形态一并定盘。

## 决策

①**Vue3+Vite+TS 港口移植非重写**：防 mXSS 安全渲染器 120 项对抗比对全等价、App/store/BotMessage/useChat 行为逐字节契约（DOM id/class/localStorage 键与格式）、新旧存储双向兼容。
②**dist 优先/legacy 回退双态**：server.py 先探 frontend/dist，缺件回退 static/index.html；/assets 指纹资产 immutable+index no-cache。
③**零 CDN/零外部请求铁律**：KaTeX 自托管（\(\)/\[\]/$$ 三组开、$ 不开）。
④设计宪法"单HTML/零构建"条款修订=同源自托管构建产物（铁律不变，条款留批次A 设计闸一并决策）。
⑤**云端部署形态落定=scp 直传非 git 仓**；**上云一律取提交态**（git show/worktree，禁 scp 工作树）。

## 理由与判据

港口式移植=风险面最小（回归网可逐位比对）；scp 形态由一次事故反证：首传误带在飞代理半成品→GET / 500→git show 提交态重传修复，遂立"取提交态"操作纪律。

## 替代方案（含被否原因）

- 维持 vanilla 单文件（弃——维护性到顶，作者授权更彻底）
- 重写（弃——行为保真无法逐位比对）
- 云端 git 仓部署（弃——落定 scp 直传）

## 后果

- **正向**：回归全绿（auth 8/8、mXSS 3/3、citation_sse 16/16、verify_ui 54/54 双主题 WCAG）；产物 gzip ≈37KB；旧件潜伏 CSS 注释吞规则 bug 揭出双侧同修（徽标样式生产从未生效→恢复设计原意）；批次B 速赢/批次D 会话同步当日续落。
- **负向/风险**：双前端形态维护面（legacy 回退保留）；act-/pv- 样式走 1.0 token 待批次A2 重刷。
- **回滚**：软回退=移走 dist 秒回 legacy；硬回滚=部署前备份位。
